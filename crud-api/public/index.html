Tasks API

A RESTful API for managing a list of tasks. Every endpoint speaks JSON and can be run live from this page.

BASE /api/tasks this app's origin

Authentication

None. This API is unauthenticated. There is no API key or Authorization header, so every endpoint is open. Don't put anything sensitive behind it as-is.

The task object

Each task has the shape { id, title, status, priority, createdAt, updatedAt }.
status is one of todoin_progressdone
priority is one of lowmediumhigh
