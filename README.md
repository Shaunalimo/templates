# VibeKit Templates

The starter templates a new VibeKit app can begin from. Each is a real, runnable app — your agent takes it from here: it customizes, extends, hosts, and keeps improving it based on what you ask for.

You don't clone these by hand. In the app, describe what you want (or pick a starter) and the agent begins from the closest match, live on your own domain in about a minute.

> [**📱 Build one from your phone →**](https://apps.apple.com/us/app/vibekit-agent-devops/id6760206636)

## The starters

Ordered by how often people actually build them.

| Template | Start here when you want… |
|----------|---------------------------|
| **dashboard** | Charts, tables, and sidebar nav over your data — the metric-at-a-glance app. |
| **game** | A 2D browser game with touch and keyboard controls, sound, and a real leaderboard. |
| **landing** | A marketing page with a real, working signup/contact form (submissions persist). |
| **ecommerce** | A storefront with products and a cart, ready to wire up checkout. |
| **tracker** | A list/CRUD app — todos, habits, budgets, inventory — with running totals. |
| **portfolio** | A personal site: projects, bio, links. |
| **saas** | An app shell with auth and a dashboard, ready for a product. |
| **form** | A focused form (contact, signup, feedback) with submissions you can read. |
| **blog** | A content site with posts and pages. |
| **crud-api** | A REST API with CRUD endpoints — the backend, no frontend assumptions. |

When no starter fits, the agent begins from a bare scaffold instead: **blank** (a web app with a JSON API and storage), **mobile** (an installable phone web app with a tab bar), or **expo** (a native iPhone and Android app).

## How it works

1. Describe your app (or choose a starter) in the [iOS app](https://apps.apple.com/us/app/vibekit-agent-devops/id6760206636) or on [vibekit.bot](https://vibekit.bot/?ref=github_templates).
2. The agent starts from the closest template and ships a first version to a live URL.
3. Keep chatting — the same agent maintains and evolves the app over time.
